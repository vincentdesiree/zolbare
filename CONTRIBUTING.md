# Contributing to Zolbare

First off, thanks for taking the time to contribute! 🎉

## Ground Rules (The Philosophy)
- **Zero JavaScript:** Any contribution to the core theme must maintain 0-JS.
- **Vanilla CSS:** No Sass, PostCSS, or heavy build steps required for users.
- **Simplicity:** Keep it lean, readable, and idiomatic.

## How to Report Bugs & Propose Features
- Open an issue on GitHub.
- Clearly describe the bug or feature, including steps to reproduce if applicable.

## Pull Request Process
1. Fork the repository and create your branch from `main`.
2. Test your changes locally using `zola serve`.
3. Ensure your CSS modifications remain lightweight and scoped properly.
4. Submit a Pull Request targeting the `main` branch.
