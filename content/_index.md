A minimalist, responsive, no-bloat theme built for [Zola](https://www.getzola.org/).

Designed around three core principles:

* **Zero JavaScript:** Fast, accessible, and privacy-friendly by default.
* **Vanilla CSS:** Native CSS variables, modern flex/grid layouts, zero build tools.
* **Content-first:** Clear typography, system font stacks, and native `prefers-color-scheme` dark mode.
